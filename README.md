A brand-new, visually stunning, highly addictive word game combining kinetic fluid letter physics, word chaining, elemental bursts, and automated iOS `.ipa` compilation.

---

## 🌟 Game Features & Hook

1. **Kinetic Letter Physics & Swiping**:
   - Drag or swipe across floating letter orbs in any direction (horizontal, vertical, diagonal, or freeform).
   - Dynamic jelly-orb physics with realistic bouncing and particle visual trails.
2. **Pivot Chaining & Combos**:
   - End a word on a letter and pivot directly into your next word starting with that letter to stack exponential **Streak Multipliers**.
3. **Elemental Reactions**:
   - 🔥 **Ignite**: 5+ letter words explode in a fiery particle burst clearing surrounding letter tiles.
   - ⚡ **Tesla Arc**: Vowel chains trigger electric arcs.
   - ❄️ **Ice Shatter**: Rare letters (Q, X, Z, K) shatter into bonus points.
4. **Procedural Web Audio API Sound Synthesizer**:
   - Dynamic ceramic orb tile clicks, musical pitch-scaled scales on letter swiping, and explosive bass drop sound effects.
5. **30 Forge Journey Sectors + 60s Blitz Mode**:
   - Play 30 handcrafted puzzle levels with specific objectives or race against the clock in 60-second Blitz Mode with local high-score tracking.

## 📱 Download iOS .IPA Package

1. Go to the **Actions** tab or **Releases** tab in this GitHub repository.
2. Select the latest workflow run or Release `v1.0.0`.
3. Download **`LexiconForge.ipa`**.
4. Install on your iOS device using **AltStore**, **Sideloadly**, **TrollStore**, or Apple Xcode.
